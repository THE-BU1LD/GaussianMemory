# Research session contract

Before work, read `RESEARCH_STATE.json` and its `canonical_read_order` sources.
Keep the retained scientific disposition, failures, protected boundaries, and
open integration work in view. The state indexes existing evidence; it does not
replace or authorize changes to frozen protocols or retained artifacts.

Before finishing, update the canonical state and add an append-only development
record for a scientifically meaningful change or important failure. Preserve
negative, mixed, invalid and inconclusive history. A successor hypothesis must
receive its own version and prospective falsifier. Generated regression tests
establish engineering behavior only; do not call them scientific experiments
supporting a research claim.

Follow the user's authorized scope and the current protected protocol. No test
pass authorizes protected outcomes, paid scientific compute, deletion of evidence,
or relabeling a completed negative study as supported.
